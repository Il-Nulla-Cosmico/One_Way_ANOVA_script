# 🌱 ANOVA Pipeline for Plant Science Data
**Author:** Carmelo Cavallaro — *"Il_Nulla_Cosmico"* · *"Battle_Horse"*

A modular R pipeline for automated statistical analysis and scientific data visualization of multi-response experimental datasets. Designed for plant science research, but applicable to any one-way ANOVA experimental design.

---

## 📋 Overview

This pipeline is split into two independent scripts:

| Script | Purpose |
|---|---|
| `script_analisi.R` | Runs all statistical tests and saves results to disk |
| `script_grafici.R` | Loads results and generates fully customizable plots |

The two-script architecture means you only re-run the analysis when your data changes. All plotting is done independently, with no need to re-run the statistics.

---

## ⚙️ Features

- ✅ Automated assumption checking (Shapiro-Wilk, Bartlett, Levene)
- ✅ Automated decision logic (standard ANOVA / Welch's ANOVA / warning)
- ✅ One-way ANOVA with Tukey HSD and Bonferroni post-hoc tests
- ✅ Significance letters generated automatically from Tukey p-values
- ✅ Letters on plots are **guaranteed to match** the console output
- ✅ Loops automatically over all response variables (Y columns)
- ✅ Column names with underscores converted to clean labels on all plots
- ✅ Full plot customization via a single `plot_variable()` function
- ✅ Export to PNG, PDF, or screen
- ✅ Assumptions summary table at the end of the analysis

## 🚀 Workflow

### Step 1 — Prepare your data

Your Excel file should have:
- **One column** for the treatment/group variable (X)
- **One or more columns** for the response variables (Y)


---

### Step 2 — Configure `script_analysis.R`

Open the script and fill in **STEP 0**:

```r
original_dataset   <- your_dataset        # Name of your imported dataset
factor_column_name <- "Factor_volume_water"  # Your X column name

measure_column_names <- c(
  "NAME Y1",
"NAMEY2", ETC...
 
  # Add all your Y variables here
)
```

Then **run the entire script**. It will:
1. Test normality and homoscedasticity for each variable
2. Run ANOVA and post-hoc tests
3. Generate significance letters automatically
4. Print an assumptions summary table
5. Save everything to `analysis_results.RDS`

### Step 3 — Read the assumptions summary

At the end of the analysis, a summary table is printed:

```
Variable              p_Shapiro  p_Homo   Decision
Altezza_al_colletto   0.4120     0.2340   OK
Diametro_fusto        0.0310     0.1820   NOT_NORMAL
Peso_secco_foglie     0.2100     0.0210   UNEQUAL_VAR
```

| Decision | Meaning |
|---|---|
| `OK` | All assumptions met. Safe to plot as standard ANOVA. |
| `NOT_NORMAL` | Normality failed. Consider Kruskal-Wallis or log-transformation. |
| `UNEQUAL_VAR` | Homoscedasticity failed. Welch's ANOVA was run automatically. |
| `BOTH_FAILED` | Both assumptions failed. Non-parametric test strongly recommended. |

---

### Step 4 — Create plots with `script_grafici.R`

Open `script_grafici.R`, run **STEP 0** to load the results, then scroll to the bottom and use `plot_variable()`.

#### Minimal usage
```r
plot_variable("Altezza_al_colletto", type = "barplot")
```

#### Available plot types
```r
plot_variable("Altezza_al_colletto", type = "barplot")
plot_variable("Altezza_al_colletto", type = "boxplot")
plot_variable("Altezza_al_colletto", type = "dotplot")
plot_variable("Altezza_al_colletto", type = "violinplot")
```

#### Full customization example
```r
plot_variable(
  variable       = "Altezza_al_colletto",
  type           = "barplot",
  colors         = c("#E06C75", "#61AFEF", "#98C379"),
  title          = "Effect of irrigation on plant height",
  x_label        = "Irrigation regime",
  y_label        = "Height at collar (cm)",
  letters        = c("a", "ab", "b"),   # optional override
  x_angle        = 45,
  theme          = "classic",
  save           = c("screen", "png", "pdf"),
  filename       = "figura1_altezza",
  dpi            = 300
)
```

## 🎨 `plot_variable()` Parameters

| Parameter | Type | Default | Description |
|---|---|---|---|
| `variable` | string | required | Response variable name |
| `type` | string | required | `"barplot"` · `"boxplot"` · `"dotplot"` · `"violinplot"` |
| `colors` | vector | greens | One HEX color per group |
| `title` | string | auto | Custom plot title |
| `x_label` | string | auto | Custom X axis label |
| `y_label` | string | auto | Custom Y axis label |
| `caption` | string | Tukey note | Caption below the plot |
| `letters` | vector | auto (Tukey) | Override significance letters |
| `show_letters` | logical | `TRUE` | Show/hide letters on barplot |
| `letter_size` | number | `5` | Font size of letters |
| `bar_width` | number | `0.5` | Width of bars |
| `errorbar_width` | number | `0.2` | Width of error bar caps |
| `point_size` | number | `2` | Size of points in dotplot |
| `jitter_width` | number | `0.2` | Horizontal spread of points |
| `alpha` | number | type-dependent | Fill transparency (0–1) |
| `outlier_color` | string | `"red"` | Color of outlier points |
| `x_angle` | number | `0` | Rotation of X axis labels |
| `base_size` | number | `12` | Base font size |
| `title_size` | number | `13` | Title font size |
| `theme` | string | type-dependent | `"classic"` · `"minimal"` · `"light"` · `"bw"` |
| `save` | vector | `"screen"` | `"screen"` · `"png"` · `"pdf"` |
| `filename` | string | auto | Base name for saved files |
| `width` | number | `8` | File width in inches |
| `height` | number | `6` | File height in inches |
| `dpi` | number | `300` | PNG resolution |
| `warn_if_failed` | logical | `TRUE` | Warn if assumptions not met |

## 📝 Notes

- Significance letters are generated from `emmeans` Tukey p-values and are guaranteed to match the console output exactly.
- Column names with underscores (e.g. `Peso_secco_foglie`) are automatically converted to clean labels (`Peso Secco Foglie`) on all plot axes and titles.
- `script_analisi.R` only needs to be re-run when the raw data changes.
- Plots can be further modified after creation using standard ggplot2 syntax:
  ```r
  p <- plot_variable("Altezza_al_colletto", type = "barplot")
  p + ylim(0, 30) + theme(legend.position = "none")
  ```
